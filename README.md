# Helmet Detection using Deep Learning

## Overview
This project detects whether a person is wearing a helmet or not using deep learning.

## Models Used
- CNN from Scratch
- VGG16 Base
- VGG16 + FFNN
- VGG16 + FFNN + Data Augmentation

## Best Model
CNN from Scratch achieved the best test performance.

## Technologies
- Python
- TensorFlow/Keras
- NumPy
- Pandas
- Matplotlib
- Seaborn
